## :file_folder: Descrição do Projeto
Feito para resolver a complexidade e o excesso de informações no mercado de criptomoedas, **CriptoSimple** mostra as criptos mais comentadas do mercado de forma simplificada, mostrando apenas o essencial: **Nome, Preço e Aumento/Decréscimo.** 

O projeto foi realizado usando `React v19.2.0` e `Tailwind CSS v4.2.1` como frameworks principais, ambos instalados por meio do `Vite v7.3.1`. Além de ter sido utilizado o `Figma MCP` para agilizar e criar da forma mais fiel possível o **Card** prototipado no Figma.

Para a requisição das informações de cada criptomoeda foi utilizada a **:hot_pepper:CoinPaprika API** - voltada para disponibilizar em tempo real **preços, volume, market cap** e muitos mais de centenas de criptomoedas.
